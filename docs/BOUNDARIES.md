# Proof and evidence boundaries

1. Lean proves the registered rational/real rounding, SQL affine gap, typed instance,
decoder, envelope, session and finite stream-machine properties under their actual
hypotheses. The catalog lists the exact imported source modules; it does not count
all declarations as independent theorems.
2. Runtime tests observe the native IO integration. OS read semantics, blocking,
compiler/runtime/hardware and startup-file authority remain external.
3. ExpectedInstance is supplied separately, but the existing --context pathname is
operator-selected without an authenticated principal/task authority registry. A
request cannot change the in-memory context; this is not proof that its original
selector was entitled to select it.
4. Python, JSON transport outside the proved Lean grammar, SHA-256 implementation,
source authenticity and physical validity are not formally verified as a whole.

The previous full Leanbook-tree audit (153 modules / 10526 declarations) is historical
and overlaps this imported subset. It is not added to standalone counts or declared
applicable merely because files match. Third obligation: OPEN.
