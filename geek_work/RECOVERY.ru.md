# Переносимый локальный снимок Markdown-представления

`geek_work_vault_recovery.py` сохраняет проверенную проекцию, полный JSON-граф и
только provenance-файлы выбранных карточек. Это приватный снимок: полный граф
содержит и невыбранные знания. Он не входит в публичный экспорт инструментов.

```sh
python3 tools/geek_work_vault_recovery.py snapshot \
  --graph YOUR_GRAPH.json --root . \
  --vault EXISTING_VAULT --vault-anchor VAULT_SHA --output NEW_SNAPSHOT
python3 tools/geek_work_vault_recovery.py verify \
  --snapshot COPIED_SNAPSHOT --anchor SNAPSHOT_SHA
```

SHA-якорь снимка возвращается первой командой; сохраните его отдельно. Для второй
команды прежний корень данных и исходный vault не нужны. Нужны закреплённые версии
инструментов, совпадающие с tool_pins снимка. Полный граф сохраняется без изменения
карточек и истории; невыбранные provenance-файлы не копируются и не проверяются.
Снимок не является резервной копией всего проекта или всех чатов.

Проверяются внешний якорь, состав и SHA файлов, версии инструментов, восстановление
Markdown-проекции и доступность выбранных источников в новом корне. Изменённый или
неполный снимок, симлинки, лишние файлы и превышение лимитов отклоняются. Лимиты:
32 MiB содержимого, 256 payload-файлов плюс seal; каждый файл также ограничен
штатным MAX_BYTES. Output создаётся новым каталогом; seal пишется последним.
При ошибке неполный каталог сохраняется для диагностики, без успешной квитанции.

Настройки/плагины `.obsidian` не копируются. Статусы needs_review и научные оговорки
сохраняются; целостность снимка не подтверждает научную истинность. Не выполняется
код из источников, нет модельного вызова, фоновой синхронизации или публикации.
Перенос в другой каталог проверяется отдельно от резервной копии на другом
устройстве. Выбор внешнего места хранения остаётся открытой задачей.
