# Release scope: Geek Work 1.0.0

This is an independently versioned tools component hosted by SimLab. The release
contains first-party code, reviewed documentation, fixed synthetic fixtures,
optional runtime source/profiles and limited ALCC aggregate metadata. It does not
claim a new full verification checkpoint for every SimLab or Leanbook module.

The release source baseline follows private PR #99. Public filenames and bytes
are fixed by MANIFEST.json; the private release PR records the reviewed export
allowlist and original hashes. Public variants make two path-only adaptations:
ALCC preflight imports its adjacent rational bridge, and the installed timing
validator locates the adjacent public tools. The earlier public synthetic memory
fixture is retained instead of copying the curated private graph.

## Validation scope

The public suite checks all bundled tests with zero tolerated skips, failures,
expected failures or unexpected successes. The private suite also covers the
unexported source/corpus integration tests. Those counts must be reported
separately. Passing a synthetic suite is not a live provider, renderer, formal
kernel, physical experiment or fresh timing benchmark.

The ALCC timing replay verifies completed fixed-corpus records supplied by the
caller. RESULTS.json supplies historical source/binary pins and observations;
measurements are not hardware-independent promises. Raw pilot logs and the native
binary are not distributed. Receipt integrity does not establish genuine execution,
clock authenticity or a Lean proof for each invocation. The installed study driver
is historical and optional; replay never runs it as a script or executes received code.

## Intentionally excluded

- Private graphs, chats, manuscripts, reviewer replies, credentials and raw logs.
- Source-corpus and saved-review tests that require these private artifacts.
- Archived virtual environments, native binaries, container images and model weights.
- Live model selection, agent orchestration, automatic publishing or deployment.
- New Lean proofs, whole-library axiom audits and broad scientific qualification.

The historical typed-ALCC replay keeps its original source bindings. Creating a
new typed-study bundle still requires those exact original inputs; this release
does not manufacture or replace them. Existing artifacts and source snapshots
remain immutable.

## Open work

Independent review and holdout evaluation, production watchdog integration,
external-device backups with a named storage location, full measured model costs,
general scientific execution, hardware-independent performance qualification and
future publications remain separate tasks. Kaggle participation remains deferred.
