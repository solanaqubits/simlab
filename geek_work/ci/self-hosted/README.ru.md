# Одноразовый оператор CI

Публичные pull request проходят hosted workflow `.github/workflows/geek-work.yml`.
Ручной `workflow_dispatch` не заменяет PR-check. Этот инструмент предназначен для
явно выбранной доверенной ревизии и не устанавливает постоянный runner-сервис.

Из корня публичного SimLab:

```sh
python3 -B geek_work/ci/self-hosted/run_once.py --help
```

Ручной маршрут, если оператор уже проверил ревизию и подготовил Docker-образ:

```sh
gh workflow run geek-work.yml --repo solanaqubits/simlab \
  --ref REVIEWED_BRANCH -f execution=isolated-self-hosted
python3 -B geek_work/ci/self-hosted/run_once.py \
  --repo solanaqubits/simlab --run-id RUN_ID --sha EXACT_HEAD_SHA \
  --output NEW_PRIVATE_RECEIPT_DIRECTORY
```

Перед запуском прочитайте Dockerfile и исходник оператора. Сборка образа — отдельная
операция с внешними зависимостями, она не выполняется установкой Geek Work или его
тестами. Нужны заранее подготовленный Docker, GitHub CLI и собственная авторизация.
Токены в исходниках не хранятся. Не передавайте секреты недоверенному PR-коду.

Результат относится только к указанным run ID и SHA. Проверяются событие, владелец,
метки и назначение временного runner. После работы проверяется удаление контейнера
и регистрации runner; `cleanup_failed` не считается успехом. Сохраняйте квитанции
приватно. Внешний GitHub, Docker и хост входят в доверенную вычислительную базу.

Реализация также содержит отдельные, жёстко ограниченные маршруты приватного
репозитория для PR/main. Они не разрешают запуск публичных PR на self-hosted
runner. Соответствующие имена репозиториев в коде и синтетических тестах — настройки
оператора; текущая публикация не раскрывает историю, данные или доступ к ним.
